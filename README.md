# Mineur

Creuse toujours plus bas avec ta foreuse, remonte les minerais, vends-les à la surface et améliore ta machine. Gare au carburant et à la lave.

Creuse à gauche, à droite ou vers le bas ; remonte par les galeries déjà creusées. Chaque coup de foret coûte du carburant. Vends à la surface pour acheter un plus gros réservoir, une plus grande soute et un meilleur foret.

Ses données (records, réglages) sont rangées dans le dossier du plugin, que NeoDex sauvegarde (synchro cloud comprise).

## Installer

Dans NeoDex : **NeoStore → À découvrir → Mineur → Installer**.

Développer un plugin : voir le [SDK NeoDex](https://github.com/NDesumeur/neodex-sdk).
